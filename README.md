# Eternia-Reid-Farah-MOD
A mod for Tales of Eternia Remastered

## About This Mod

This mod adds the following artes to the Artes menu:

- **Reid:** Gurenken and Dankuken
- **Farah:** Kairyuken and Raisenken

All four artes can be used as **Arcane Artes**.

The mod has undergone limited testing, so please use it at your own risk.

## Installation

1. Close the game and extract all files from the downloaded ZIP archive. **Do not run files directly from inside the ZIP.**
2. Double-click `Apply.cmd` in the extracted folder.
3. The installer will automatically attempt to locate the game using Steam's registry information. If the game cannot be found, manually select the folder containing the game's `.exe` file.
4. Once the installation is complete, launch the game normally through Steam.

### Additional Notes

- You can extract the files anywhere, including your desktop. They do not need to be placed inside the game folder.
- You can also drag and drop the game folder onto `Apply.cmd` to specify its location.
- If you encounter an "Access Denied" error, right-click `Apply.cmd` and select **Run as administrator**.
- Installation will be aborted if an unsupported game version or an incompatible version of an existing mod is detected.
- If you are using an older version of this mod, run `Restore.cmd` from that version first to remove its mod files before installing the latest version.

## Uninstallation

1. Close the game.
2. Run `Uninstall.cmd` from the extracted mod folder.
3. When the game launches, load a save file that uses this mod.
4. Open the in-game menu.
5. Confirm that the four additional artes have disappeared from the Artes menu.
6. Save your game.
7. Exit the game.

Afterward, the uninstaller will automatically remove the mod files.

**Do not close the command window while the uninstallation process is running.**

### Additional Notes

- If you have multiple save files that use this mod, repeat the load → open menu → save process for each save file from which you want to remove the mod.
- `Restore.cmd` only removes the mod files and is primarily intended for updating the mod.
- For normal uninstallation, use `Uninstall.cmd`.

## Important Notes

- **Keep the extracted mod folder even after installation.**
- Files and folders such as `backup`, `rollback.json`, and `SaveBackup` are created during installation for backup and recovery purposes. Do not delete or redistribute them.
- Do not move `Apply.cmd` by itself. Keep all files together in the original extracted folder.
- As a precaution, it is strongly recommended to create a separate backup save before installing the mod.
- Compatibility with other mods is not guaranteed.
- Future game updates may cause this mod to stop working.
- This mod has not been tested throughout the entire story or in every special battle.
